# Roadmap

本路线图只展示 Core 和少量 Support。图表美化、分享导出、多 provider 扩展、Canvas/Bases/HTML 输出和泛用 dashboard 能力不进入主线；它们只有在服务于扫描、候选、审核、决策和受保护 Markdown 年报闭环时才会重新评估。

## Now: 跑通可信小闭环

- 扫描范围选择：年份、包含目录、排除目录、隐私模式。
- 候选生成：年度主题、候选回看笔记、项目/任务线索、异常活动、沉睡资产。
- 候选理由：每个候选项包含“为什么被选中”和 evidence links。
- Review Board 基础操作：展示推荐理由和证据链接，并支持确认、重命名、合并、忽略、归档。
- 行动决定：继续、合并、归档、放弃、转项目、未来复核。
- Markdown 年报：写入已确认主题、代表笔记、行动决定、方法说明和证据链接。
- 用户编辑保护：生成区块和用户手写区块分离，重新生成不覆盖手写内容。
- 默认隐私边界：无网络、无外部 AI、无 telemetry。

## Next: 降低审核成本

- 候选分组：按主题、月份、项目路径、任务线索和沉睡资产分组。
- 候选合并建议：发现重复主题和相近代表笔记。
- 证据预览：在 Review Board 中快速查看源笔记摘录、反链和任务状态。
- 审核进度：展示待审核、已确认、已忽略、需决策数量。
- 重建索引反馈：展示扫描进度、排除数量和候选生成状态，不扩展成泛用 dashboard 指标墙。
- 冲突处理：目标年报已被编辑时，提供 diff、新副本或备份路径。

## Later: 增强可复核性

- 发送前 AI 上下文预览：仅在用户显式启用 AI 时展示 provider、摘录数量和排除范围。
- 字段级隐私控制：允许从 AI 或候选上下文中排除特定路径、标签或 frontmatter 字段。
- 年报再生成记录：记录每次生成的范围、候选数量和用户确认数量。
- 历史 Review Session：允许继续上次未完成的年度复盘。
- 手动补充候选：用户可以把任意笔记加入本次复盘。
- Obsidian 原生发布准备：README、manifest、版本 release artifact 和社区插件提交材料保持一致。

## Explicitly Not On The Main Roadmap

- 以 AI provider 数量作为主功能。
- 默认外部 AI 总结。
- 泛用图表库或复杂数据大屏。
- 面向普通用户的 agent 安装主路径。
- 分享卡、HTML 导出、Canvas 导出等复盘闭环外的输出形式。
- 依赖 Dataview、Bases、Tasks、Kanban、Projects 等第三方插件完成核心路径。
